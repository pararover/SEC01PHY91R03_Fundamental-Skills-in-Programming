\section{Arrays, matrices and vectors}
	\begin{itemize}
		\item \textit{Array}: A collection of elements arranged in a regular grid with one or more dimensions. Elements of a Scilab numeric array share the same numeric type. Arrays may be 1-D, 2-D, or higher dimensional.
		
		\item \textit{Matrix}: A two-dimensional numeric array with rows and columns. Matrices are the primary data structure for linear algebra in Scilab.
		
		\item \textit{Vector}: A one-dimensional array. In Scilab a vector is represented either as a row vector (1 × n) or a column vector (n × 1); both are special cases of matrices.
	\end{itemize}
